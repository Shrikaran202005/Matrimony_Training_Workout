--------------------------------------------------------------------------------
1. IMAGE PROCESSING IMPLEMENTATION (src/services/image.service.ts)
--------------------------------------------------------------------------------

- Reads the uploaded original image buffer from disk using fs-extra.
- Runs three Sharp resizing pipelines:
  * Thumbnail (100x100): Uses fit: 'cover' to crop cleanly to square dimensions
    and saves as JPEG at quality 80 in uploads/thumbnails/.
  * Medium (300x300): Uses fit: 'cover' and saves as JPEG at quality 85 in
    uploads/medium/.
  * Large (800x800): Uses fit: 'inside' to preserve original aspect ratio
    within an 800x800 bounding box and saves as JPEG at quality 90 in
    uploads/large/.
- Returns the relative paths for each generated version.

--------------------------------------------------------------------------------
2. EXPLANATION OF CORE PACKAGES
--------------------------------------------------------------------------------

1. multer (Multipart Form-Data & Disk Storage)
   - Purpose: Middleware for handling multipart/form-data file uploads in Express.
   - Implementation: Configured in src/middleware/upload.ts with diskStorage to
     save incoming files to uploads/originals/ using a collision-free filename
     format (<uuid>-<sanitized-originalname><ext>) and an upload size cap read
     from MAX_FILE_SIZE.

2. sharp (High-Performance Image Processing)
   - Purpose: Fast native Node.js image resizing, cropping, and compression
     powered by libvips.
   - Implementation: Used in src/services/image.service.ts to convert uploaded
     images into standardized thumbnail (100x100), medium (300x300), and large
     (800x800) versions with tuned fit modes and JPEG quality settings.

3. joi (Schema-Based Input Validation)
   - Purpose: Declarative data validation with custom error messaging.
   - Implementation: Configured in src/middleware/validation.ts to enforce
     strict rules on filename, allowed MIME types (image/jpeg, image/png,
     application/pdf), and maximum file size (5MB) before processing or
     persisting file metadata.
